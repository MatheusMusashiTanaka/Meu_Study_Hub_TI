# Toque de Mulher

Plataforma de e-commerce para o setor de beleza, desenvolvida para digitalizar as operações de uma loja de cosméticos e produtos de cuidado pessoal, com vitrine virtual, painel administrativo e integração de pagamento.

- **Frontend:** TypeScript — [toquedemulher-frontend](https://github.com/ToqueDeMulher/toquedemulher-frontend)
- **Backend:** Python — [toquedemulher-backend](https://github.com/ToqueDeMulher/toquedemulher-backend)
- **Documentação:** [docs](https://github.com/ToqueDeMulher/docs)

> Projeto em desenvolvimento contínuo (MVP em validação), usado aqui como parte do meu portfólio prático em desenvolvimento de software.
